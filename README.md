# Web de ejemplo

## Instalación manual
Copiar el contenido de la carpeta `web` en la carpeta del hosting usando FTP, SFTP, etc.

## Instalación automática

Editar el fichero `.env` con los datos de FTP y el hosting. Hay un fichero de ejemplo `.env_ejemplo`. Cambiar el nombre a `.env`

Ejecutar:

```
./sync_ftp.sh
```
